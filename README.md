# Salis 3 Hottes

Site commercial et première couche CRM. La marque publique est **Salis 3 Hottes**. Zones actives : **Paris**, **Perpignan**, **Troyes** et **Dijon**. La source de vérité métier est `src/lib/site.ts`.

Le brief historique ci-dessous a servi de cahier des charges initial (marque provisoire). Il n'est plus la source de vérité du site.

# Extraction Excellence

Construis un prototype web commercial premium, extrêmement moderne, crédible et interactif pour une nouvelle entreprise française spécialisée dans le dégraissage professionnel des hottes, conduits, filtres, moteurs et systèmes d’extraction des cuisines professionnelles.

Ce projet est destiné à être présenté à la direction de l’entreprise comme prototype officiel du futur site web commercial.

Le prototype doit donner immédiatement l’impression d’une entreprise :

moderne ;

fiable ;

technique ;

premium ;

structurée ;

réactive ;

spécialisée dans les cuisines professionnelles ;

beaucoup plus avancée digitalement que les sociétés traditionnelles de nettoyage.

Ne crée surtout pas un site générique de nettoyage.

Le design doit évoquer davantage :
maintenance industrielle + expertise technique + sécurité + propreté premium + SaaS B2B moderne
que « société de ménage ».

1. CONTEXTE

L’entreprise vient d’être créée en France et commencera son activité en septembre 2026.

Elle possède deux pôles :

Paris / Île-de-France

Perpignan / Pyrénées-Orientales

Elle cible principalement :

restaurants ;

hôtels ;

fast-foods ;

boulangeries ;

pâtisseries ;

cuisines collectives ;

traiteurs ;

établissements alimentaires professionnels.

L'objectif principal du site est de :

présenter l'entreprise ;

inspirer confiance ;

se différencier visuellement des concurrents ;

générer des demandes de devis ;

qualifier les prospects ;

faciliter la prise de contact ;

proposer WhatsApp ;

proposer un chatbot intelligent ;

préparer l'intégration future avec un CRM ;

créer une expérience client beaucoup plus fluide que les concurrents.
